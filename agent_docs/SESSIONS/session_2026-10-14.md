## Lessons Learned

- Stopping `npm run dev` by its PID leaves the forked `next-server` alive; stop the process group and verify the listener. My own validation hit this before the rules did.
- `pkill -f <pattern>` matches the shell running the script that contains the pattern; select processes by cwd/name instead.
- A dev-server test without env variables never reaches the agent-rules step (instrumentation throws first); use nonsecret fixtures, never factory settings.
