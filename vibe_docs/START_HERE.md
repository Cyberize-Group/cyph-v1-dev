# Welcome to your pilot workspace

Your AI helper is called **Vibe Cody**. It handles setup and the technical work. You tell it what you see and, when proposal work is authorized, what you would like the app to do.

Cyberize Engineering supplies your starting message, a private settings file and a test login. Keep the settings file and password out of AI chat, screenshots and GitHub.

## Start here

1. Use the supplied download/clone instructions and open the project folder in the approved AI tool. If you need help with that, Cyberize Engineering will give instructions for your computer.
2. Start a new chat and say **Hi**.
3. At the workflow question choose **1 — Guest frontend proposal**.
4. Paste the complete starting message Cyberize Engineering gave you.
5. Vibe Cody prepares your workspace. When asked, place the supplied `.env.local` file in the project folder, beside `package.json`, and say **saved**. The file must be named exactly `.env.local`, not `.env.local.txt`. Ask for one simple step at a time if you cannot see where to put it.
6. Vibe Cody starts the app and gives you the local browser address. Open it and use your test login.

You do not need to choose a branch, interpret a version ID, run installation commands or repair a database. Vibe Cody handles the authorized steps and explains any computer permission prompt in ordinary language. If a tool cannot perform a step, it tells Cyberize Engineering what is missing.

## This rehearsal

We are checking setup and login. Open the pages Vibe Cody names and tell it whether they appear. The assigned admin test account should show OwedBook, Profile and Admin Portal. Look for the **Demo · mock data** marker where the rehearsal expects it. Report what you actually see; do not change records just to test a screen.

The pilot may be shared with other guests. Use only the test account and settings supplied for this session. If data looks real or unfamiliar, stop and tell Cyberize Engineering.

When the checks are finished, say **close the rehearsal**. Vibe Cody stops the server it started, verifies that it stopped and gives a short result. Closing the chat alone is not the stop procedure. Next time, open the same project and start a fresh chat with your supplied message; the AI checks the existing workspace before resuming.

## Later, when proposal work is approved

Vibe Cody asks what you want to improve in normal product language. You can describe an idea without knowing file names or implementation details. It checks whether the idea fits the approved workspace. Changes outside that scope are referred to Cyberize Engineering.

Your AI prepares an honest journal and proposal for review when submission is authorized. Cyberize Engineering handles adoption and QA. The proposal is a starting point for the factory, not a direct change to the main app.

## Getting help

If setup fails, Vibe Cody gives you a short message to forward to **Cyberize Engineering**. You should not need to diagnose technical errors or choose a workaround.

This repository is public. Published code, branches and proposals are visible to other people. Never publish passwords, connection files or real patient/pharmacy information. The settings file is excluded from normal Git staging, but that is not a guarantee against accidental copying or forced uploads.
